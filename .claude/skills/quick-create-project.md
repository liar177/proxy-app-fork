# 快速创建代理项目

当用户请求"快速创建项目"、"添加代理"等时，按以下流程操作。

## 流程

### 1. 收集信息

向用户确认以下信息（用户可能已经提供了部分）：

- **项目名称**（必填，需唯一）
- **目标地址**（必填，如 `http://localhost:5173`）
- **项目描述**（可选，默认使用项目名称）
- **是否需要 headers**（可选，如 cookie）

如果用户未提供完整信息，用 AskUserQuestion 询问缺失项。

### 2. 自动分配端口

调用 MCP 工具 `list_projects`，从返回结果中提取所有已用端口，然后生成一个 10000-60000 范围内的未使用端口。

### 3. 调用创建

调用 MCP 工具 `create_project`，参数：

- `name`: 项目名称
- `port`: 自动分配的端口
- `description`: 项目描述（默认同名称）
- `configs`: `[{ targetAddress: 目标地址, headers: {...} }]`（如有 headers 则传入）

### 4. 确认结果

将创建结果展示给用户，包含项目 ID、名称、端口、地址。然后询问是否需要立即启动代理（调用 `start_proxy`）。
