# Todo 代理测试项目说明

## 项目结构

```
proxy-app/
├── test-todo-backend/     # NestJS 后端服务 (端口 3001)
├── test-todo-frontend/    # React 前端应用
└── proxy-backend/         # 代理服务 (端口 3000)
```

## 服务配置

### 后端服务 (test-todo-backend)
- 端口: 3001
- API 前缀: `/api/todos`
- 启动命令: `npm run start:prod`

### 代理服务 (proxy-backend)
- 端口: 3000
- 代理项目配置目标地址: `http://localhost:3001`

### 前端应用 (test-todo-frontend)
- API 地址: `http://localhost:8080` (代理端口)

## 代理配置步骤

### 1. 启动 Todo 后端服务
```bash
cd test-todo-backend
npm install
npm run build
npm run start:prod
```

### 2. 创建代理项目
通过 proxy-backend 的 API 创建代理项目：

```bash
curl -X POST http://localhost:3000/project/create \
  -H "Content-Type: application/json" \
  -d '{
    "name": "Todo代理测试",
    "port": 8080,
    "description": "测试代理转发功能",
    "configs": [
      {
        "targetAddress": "http://localhost:3001",
        "headers": {
          "X-Proxy-Test": "true",
          "Cookie": "SESSIONID=test_proxy_session"
        }
      }
    ]
  }'
```

### 3. 启动代理服务
```bash
curl -X POST http://localhost:3000/project/action/start \
  -H "Content-Type: application/json" \
  -d '{"id": 1}'
```

### 4. 启动前端应用
```bash
cd test-todo-frontend
npm install
REACT_APP_API_URL=http://localhost:8080 npm start
```

## API 接口列表

| 接口 | 方法 | 功能 |
|------|------|------|
| `/api/todos` | GET | 获取所有任务 |
| `/api/todos/:id` | GET | 获取单个任务 |
| `/api/todos` | POST | 创建新任务 |
| `/api/todos/:id` | PUT | 更新任务 |
| `/api/todos/:id` | DELETE | 删除任务 |

## 测试场景

### 场景1: 基础请求转发
- 请求: `GET http://localhost:8080/api/todos`
- 期望: 请求被转发到 `http://localhost:3001/api/todos`
- 验证: 返回任务列表

### 场景2: 跨域请求
- 前端直接访问会有跨域问题
- 通过代理转发后应正常工作

### 场景3: 请求头修改
- 配置自定义请求头
- 验证后端能收到自定义头

### 场景4: POST 请求转发
- 请求: `POST http://localhost:8080/api/todos`
- Body: `{"title": "测试任务", "description": "测试描述"}`
- 期望: 任务被成功创建
